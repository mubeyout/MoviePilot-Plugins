## MetatubeSource 插件识别处理逻辑顺序

根据代码分析，该插件的识别处理流程如下：

---

### 一、主流程（劫持系统识别方法）

```
┌─────────────────────────────────────────────────────────────┐
│                    媒体识别请求进入                           │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
              ┌───────────────────────────────┐
              │  1. 检查是否匹配 Metatube 关键词  │
              │     (_match_keywords)           │
              └───────────────────────────────┘
                    │                    │
                 匹配 ✓                不匹配 ✗
                    │                    │
                    ▼                    ▼
    ┌──────────────────────┐    ┌──────────────────────┐
    │ 2. 直接由 Metatube 处理 │    │ 3. 交由系统 TMDB 识别  │
    │    recognize_media()   │    │    (原始方法)          │
    └──────────────────────┘    └──────────────────────┘
           │                           │
        成功/失败                    成功/失败
           │                           │
           ▼                           ▼
    ┌──────────────────┐       ┌──────────────────┐
    │ 返回结果           │       │ 成功 → 返回结果    │
    │ (失败不回退系统)    │       │ 失败 → Metatube兜底│
    └──────────────────┘       └──────────────────┘
```

---

### 二、Metatube 内部识别流程 (`recognize_media`)

```
┌─────────────────────────────────────────────────────────────┐
│                    1. 提取番号                               │
│   优先级：org_string > cn_name > en_name > name              │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
              ┌───────────────────────────────┐
              │  2. 检测内容分类类型             │
              │     (_detect_category_type)    │
              │  优先级：日系 > 欧美系 > 中文系 > 其他 │
              └───────────────────────────────┘
                              │
                              ▼
              ┌───────────────────────────────┐
              │  3. 是否使用 ThePornDB？        │
              │  (欧美系 + 已启用 + 有Token)    │
              └───────────────────────────────┘
                    │                    │
                  是 ✓                 否 ✗
                    │                    │
                    ▼                    ▼
    ┌──────────────────────┐    ┌──────────────────────┐
    │ 4a. ThePornDB 识别    │    │ 4b. Metatube API 识别 │
    │  - search_scenes()    │    │  - search(number)     │
    │  - get_scene_detail() │    │  - get_detail()       │
    └──────────────────────┘    └──────────────────────┘
                              │
                              ▼
              ┌───────────────────────────────┐
              │  5. 识别结果处理                │
              │  成功 → 转换为 MediaInfo 返回   │
              │  失败 → 检查 keyword_failed_download │
              └───────────────────────────────┘
                              │
                       失败且启用自动下载
                              │
                              ▼
              ┌───────────────────────────────┐
              │  6. 归类为对应分类并返回         │
              │  如："成人/日系"、"成人/欧美系"等  │
              └───────────────────────────────┘
```
