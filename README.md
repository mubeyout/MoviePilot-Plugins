## 📋 插件简介

MetatubeSource 是一个强大的番号识别插件，通过 Metatube API 和 ThePornDB API 识别番号媒体信息，支持自动分类（日系/欧美系/中文系/其他），内置42个排除关键字，支持 JSON 格式关键字配置文件。

### 主要功能
- ✅ **多源识别**：支持 Metatube API 和 ThePornDB API
- ✅ **智能分类**：自动识别内容类型并归类（成人/日系、成人/欧美系等）
- ✅ **排除机制**：内置42个排除关键字（画质、分辨率、编码等）
- ✅ **JSON配置**：支持外部 JSON 文件管理关键字（无需额外依赖）
- ✅ **兜底下载**：识别失败时可选择自动归类并下载
- ✅ **详细日志**：记录所有识别历史，支持追踪和调试

### 一、主流程（劫持系统识别方法）

```
┌─────────────────────────────────────────────────────────────┐
│                    媒体识别请求进入                           │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
              ┌───────────────────────────────┐
              │  1. 检查是否匹配 Metatube 关键词  │
              │     (_match_keywords)           │
              └───────────────────────────────┘
                    │                    │
                 匹配 ✓                不匹配 ✗
                    │                    │
                    ▼                    ▼
    ┌──────────────────────┐    ┌──────────────────────┐
    │ 2. 直接由 Metatube 处理 │    │ 3. 交由系统 TMDB 识别  │
    │    recognize_media()   │    │    (原始方法)          │
    └──────────────────────┘    └──────────────────────┘
           │                           │
        成功/失败                    成功/失败
           │                           │
           ▼                           ▼
    ┌──────────────────┐       ┌──────────────────┐
    │ 返回结果           │       │ 成功 → 返回结果    │
    │ (失败不回退系统)    │       │ 失败 → Metatube兜底│
    └──────────────────┘       └──────────────────┘
```

---

### 二、Metatube 内部识别流程 (`recognize_media`)

```
┌─────────────────────────────────────────────────────────────┐
│                    1. 提取番号                               │
│   优先级：org_string > cn_name > en_name > name              │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
              ┌───────────────────────────────┐
              │  2. 检测内容分类类型             │
              │     (_detect_category_type)    │
              │  优先级：日系 > 欧美系 > 中文系 > 其他 │
              └───────────────────────────────┘
                              │
                              ▼
              ┌───────────────────────────────┐
              │  3. 是否使用 ThePornDB？        │
              │  (欧美系 + 已启用 + 有Token)    │
              └───────────────────────────────┘
                    │                    │
                  是 ✓                 否 ✗
                    │                    │
                    ▼                    ▼
    ┌──────────────────────┐    ┌──────────────────────┐
    │ 4a. ThePornDB 识别    │    │ 4b. Metatube API 识别 │
    │  - search_scenes()    │    │  - search(number)     │
    │  - get_scene_detail() │    │  - get_detail()       │
    └──────────────────────┘    └──────────────────────┘
                              │
                              ▼
              ┌───────────────────────────────┐
              │  5. 识别结果处理                │
              │  成功 → 转换为 MediaInfo 返回   │
              │  失败 → 检查 keyword_failed_download │
              └───────────────────────────────┘
                              │
                       失败且启用自动下载
                              │
                              ▼
              ┌───────────────────────────────┐
              │  6. 归类为对应分类并返回         │
              │  如："成人/日系"、"成人/欧美系"等  │
              └───────────────────────────────┘
```

## ⚙️ 配置说明

### 基础配置
```yaml
# 插件设置
enabled: true                              # 启用插件
api_url: http://127.0.0.1:8080            # Metatube API 地址
timeout: 30                                # API 超时时间（秒）
strict_match: false                        # 是否严格匹配（区分大小写）
```

### 关键字配置
插件支持两种关键字配置方式：

**方式 1：通过 UI 配置**
- 日系关键词：`SSIS, FC2, HEYZO...`
- 欧美系关键词：`BRAZZERS, BLACKED, TUSHY...`
- 中文系关键词：`MD, 约炮, 探花...`
- 其他关键词：`高清, 无码, 有码...`
- 排除关键词：`4K, UHD, HDR...`

**方式 2：通过 JSON 文件配置**
编辑插件根目录的 `keywords.json`：
```json
{
  "japanese": ["SSIS", "FC2", "HEYZO"],
  "western": ["BRAZZERS", "BLACKED", "TUSHY"],
  "chinese": ["MD", "约炮", "探花"],
  "other": ["高清", "无码", "中文字幕"],
  "exclude": ["4K", "UHD", "HDR"]
}
```

### 高级配置
```yaml
# ThePornDB 配置（欧美系内容）
theporndb_enabled: true                   # 启用 ThePornDB
theporndb_api_token: "your_token_here"    # API Token

# 命名规则
naming_template: number_actor_year        # 命名模板
max_actors: 2                             # 最多显示演员数

# 失败处理
failed_download_control: true             # 识别失败后自动归类并下载
show_failure_detail: true                 # 显示详细失败原因
```

## 🔍 排除关键字说明

### 内置排除关键字（42个）

| 分类 | 关键字 |
|------|--------|
| **画质** | 4K, UHD, HDR, FHD, HD, SD |
| **分辨率** | 2160P, 1080P, 720P, 480P, 360P |
| **帧率** | 60FPS, 120FPS, 240FPS |
| **视频编码** | H.265, H.264, HEVC, XVID, X264, X265, VC-1, VP9, AV1 |
| **音频编码** | AC3, DTS, AAC, FLAC |
| **来源** | REMUX, WEB-DL, WEBRIP, BLURAY |
| **制式** | NTSC, PAL, SECA |
| **分片** | CD1, CD2, DISC1, DISC2 |

### 排除关键字的作用
当文件名匹配到排除关键字时，会跳过成人分类，避免误分类。

**示例**：
- `电影名称.4K.UHD.BluRay.x264.mp4` → 匹配到 `4K`、`UHD`、`x264`，跳过分类
- `SSIS-001.CD1.mp4` → 匹配到 `CD1`，跳过分类

## 🚀 使用建议

### 1. 快速开始
1. 启用插件
2. 配置 Metatube API 地址（默认 `http://127.0.0.1:8080`）
3. 根据需要添加自定义关键字

### 2. 排除误分类
如果发现某些非成人内容被误分类，可以：
- 在"排除关键词"中添加相关关键字
- 或编辑 `keywords.json` 文件的 `exclude` 字段

### 3. 欧美系内容识别
启用 ThePornDB 后，欧美系内容会自动使用 ThePornDB API 识别，准确率更高。

### 4. 查看识别记录
在插件详情页面可以查看所有识别历史，包括成功和失败的记录。

## 🛠️ 故障排查

### 1. Metatube API 连接失败
- 检查 API 地址是否正确
- 确认 Metatube 服务是否运行
- 测试 API 连接（插件配置页面的"测试连接"按钮）

### 2. ThePornDB 识别失败
- 确认 API Token 是否正确
- 检查网络连接
- 查看识别日志获取详细错误信息

### 3. JSON 配置文件无效
- 验证 JSON 格式：https://jsonlint.com/
- 检查文件编码是否为 UTF-8
- 查看插件日志获取错误详情
