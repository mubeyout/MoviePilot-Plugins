# MetatubeSource 插件

## 功能说明

通过 Metatube API 识别番号媒体信息。当 MoviePilot 无法识别时，会自动调用此插件进行识别。

## 支持的番号格式

- XXX-123 (如: SONE-702, ABC-123)
- XXX123 (如: ABC123)
- n1234 (如: n1234)

## 配置项

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 启用插件 | 开启插件功能 | 关闭 |
| 媒体识别 | 启用媒体识别功能 | 关闭 |
| 使用代理服务器 | 通过代理访问 Metatube API | 关闭 |
| Metatube API地址 | Metatube API 服务地址 | http://op.mubey.top:3244 |

## 使用说明

1. 在 MoviePilot 插件市场安装本插件
2. 启用插件并开启"媒体识别"功能
3. 当 MoviePilot 无法识别文件时，会自动调用此插件
4. 插件会自动从文件名中提取番号并调用 Metatube API 获取媒体信息

## API 返回信息

- 标题
- 番号
- 演员
- 发布日期
- 评分
- 封面图
- 提供者(来源网站)
- 主页链接

## 工作原理

1. 拦截 MoviePilot 的媒体识别请求
2. 当系统无法识别时，尝试从文件名中提取番号
3. 调用 Metatube API 搜索番号
4. 将返回的媒体信息转换为 MoviePilot 格式
5. 返回识别结果

## 注意事项

- 插件仅在 MoviePilot 无法识别时才会被调用
- 需要确保 Metatube API 服务可访问
- 番号格式需要符合标准格式才能正确提取
- 识别的媒体类型默认为电影
