# ANiStrm 插件更新日志

## v2.7.0 (2026-02-06)

### 🎉 重大新功能：季度文件夹模式

#### 什么是季度文件夹模式？

这是一个全新的存储组织方式，生成符合媒体库标准的文件结构，完美解决**同一番剧多季度**的问题！

**两种存储模式对比**：

##### 模式 A：扁平模式（flat，默认）

```
/downloads/strm/
└── Dr.STONE 新石紀/
    ├── [ANi]Dr.STONE 新石紀[01][1080P].mp4.strm
    ├── [ANi]Dr.STONE 新石紀[24][1080P].mp4.strm
    ├── [ANi]Dr.STONE 新石紀 STONE WARS[01][1080P].mp4.strm  ← 第2季混合在一起
    └── [ANi]Dr.STONE 新石紀 STONE WARS][12][1080P].mp4.strm
```

**优点**：简单直接，文件名保持原始格式
**缺点**：媒体服务器可能无法正确识别季度信息

---

##### 模式 B：季度文件夹模式（season_folder，推荐）✨

```
/downloads/strm/
└── Dr.STONE 新石紀/
    ├── Season 01/
    │   ├── Dr.STONE 新石紀 S01E01.mp4.strm  ← 自动重命名
    │   ├── Dr.STONE 新石紀 S01E02.mp4.strm
    │   └── Dr.STONE 新石紀 S01E24.mp4.strm
    └── Season 02/
        ├── Dr.STONE 新石紀 S02E01.mp4.strm  ← 第2季自动归档
        ├── Dr.STONE 新石紀 S02E02.mp4.strm
        └── Dr.STONE 新石紀 S02E12.mp4.strm
```

**优点**：
- ✅ **符合媒体库标准**：Emby/Plex/Jellyfin 完美识别
- ✅ **自动季度识别**：智能识别番剧是第几季
- ✅ **自动集数提取**：从文件名提取集数并重命名
- ✅ **多季归档**：同一IP的不同季度自动归类到对应 Season 文件夹
- ✅ **刮削准确**：媒体服务器自动匹配正确的季度和集数

---

### 🔧 核心功能

#### 1. 智能季度识别

**手动映射表**（优先级最高）：
```python
multi_season_anime = {
    "Dr.STONE": {"2019-7": 1, "2020-1": 2},
    "转生王女与天才千金的魔法革命": {"2023-4": 1, "2025-1": 2},
    # 可持续添加...
}
```

**自动推断逻辑**：
- 首次出现的季度默认为第1季
- 后续季度按出现顺序递增
- 支持番剧名称关键词匹配

#### 2. 集数提取算法

支持多种常见命名格式：
- `[01]` → 第1集
- `EP01` → 第1集
- `第01集` → 第1集
- `S01E01` → 第1集
- `- 01` → 第1集

#### 3. 标准文件命名

**格式**：`番剧名 S01E01.扩展名`

示例：
- 原始：`[ANi]Dr.STONE 新石紀[01][1080P][Baha][WEB-DL].mp4`
- 标准：`Dr.STONE 新石紀 S01E01.mp4`

### 📝 配置说明

#### 新增配置项

| 配置项 | 可选值 | 默认值 | 说明 |
|--------|--------|--------|------|
| `storage_mode` | `flat` / `season_folder` | `flat` | 存储模式选择 |

#### 在插件界面配置

1. 打开 ANiStrm 插件设置
2. 找到"存储模式"选项
3. 选择：
   - **扁平模式（默认）**：保持原有行为
   - **季度文件夹模式（标准媒体库）**：使用新的季度组织方式
4. 保存配置

#### 使用建议

**推荐使用季度文件夹模式，如果：**
- ✅ 使用 Emby/Plex/Jellyfin 作为媒体服务器
- ✅ 有大量跨季度番剧
- ✅ 追求自动化的媒体库管理
- ✅ 希望媒体服务器正确识别季度

**使用扁平模式，如果：**
- ✅ 已有完善的媒体库整理方案
- ✅ 习惯手动管理文件
- ✅ 使用自定义刮削规则

### 🐛 已知问题

1. **季度识别准确率**：依赖手动映射表，未知番剧可能识别错误
2. **集数提取失败**：特殊命名格式可能无法提取集数
3. **番剧名称变更**：不同季度使用完全不同的名称可能无法识别为同一番剧

**解决方案**：
- 手动维护 `multi_season_anime` 映射表
- 使用文件重命名工具预处理文件
- 在媒体服务器中手动合并季度

## v2.6.0 (2026-02-06)

### 🎉 新增功能

#### 多视频格式支持
现在插件支持所有常见的视频格式，不再局限于 `.mp4`：

**支持的视频格式：**
- `.mp4` - MP4 视频
- `.mkv` - Matroska 视频
- `.avi` - AVI 视频
- `.mov` - QuickTime 视频
- `.wmv` - Windows Media 视频
- `.flv` - Flash 视频
- `.webm` - WebM 视频
- `.m4v` - iTunes 视频
- `.ts` - MPEG 传输流
- `.rmvb` - RealMedia 变量比特率

## v2.5.0 (2026-02-06)

### 🔧 关键修复

**问题**：插件只获取番剧文件夹名称，无法获取实际视频文件

**修复内容**：
1. 新增 `get_anime_episodes()` 方法，获取番剧内的所有视频文件
2. 修改 `get_season_list()` 只返回番剧文件夹列表
3. 更新 `__task()` 方法的 "指定季度" 和 "全部季度" 模式逻辑
4. 增强 `__touch_strm_file()` 支持子文件夹路径和自动创建目录

**测试结果** (2019-7季度)：
- 番剧数量：1部 (Dr.STONE 新石紀)
- 视频文件：24个
- 成功创建：24个 strm 文件
